## Decisions

### 1. Next.js App Router
Chosen for modern routing and API integration support.

### 2. Tailwind CSS
Used for faster responsive UI development.

### 3. Anthropic AI
Used for dynamic AI-generated audit summaries.

### 4. localStorage Persistence
Used for simple audit history storage during MVP stage.

### 5. Hardcoded Audit Logic
Used instead of AI because deterministic pricing logic is more reliable and explainable.
